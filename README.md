# 🎓 CampusConnect

An intelligent digital campus platform for student networking,
collaboration, blogging, communities, events, clubs,
hackathons, and project discovery.

## 🚀 Features

- Student Profiles
- Networking
- Social Feed
- Blogging
- Groups
- Group Chat
- Clubs
- Events
- Hackathon Team Finder
- Project Collaboration
- Intelligent Matching
- Resources
- Notifications

## 🛠️ Tech Stack

### Frontend
React + TypeScript + Vite

### Backend
Java + Spring Boot

### Database
PostgreSQL

### Advanced
Redis + WebSocket + AWS S3

### DevOps
Docker + GitHub Actions + AWS
